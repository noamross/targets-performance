# Interactive console (Positron MCP)
In Positron, run R through the `positron` MCP server, not `Rscript`/`source()`. Write the script to disk for reproducibility, then send its contents to a console so the user sees what runs and can inspect objects. Applies to small calculations and short scripts; run large scripts and `tar_make()` pipelines with `rig run`/`Rscript`.
- Console choice: use a fresh console or your own, never the user's. Don't overwrite objects in the user's session. Start one with `run_positron_command(command_id = "workbench.action.language.runtime.getRegisteredRuntimes")` (read the R `runtimeId`; it changes with R version), then `command_id = "workbench.action.language.runtime.startNewConsoleSession", args = ["<runtimeId>"]` (returns `sessionId`). Reuse that session for the rest of the task.
- Run code: `execute_code(code, session_id, language = "R")` (shows in the console and history; use for anything with side effects). `evaluate_code` inspects state without history. Output is in `stdout`; empty output is not a failure, so don't retry state-changing calls.
- Base answers on inspected objects: `print()`, `str()`, `head()`, `plot()` (read with `get_plot`), `View()` for large data frames. Show pipeline results with `tar_load()`/`tar_read()` then print or `View()`, instead of describing them, but additional descriptions are fine if warranted.
- When displaying results of a script or function in a pipeline, also open the script in the Positron editor (`run_positron_command(command_id = "vscode.open", args = ["<absolute path>"])`), but do not open many scripts in the editor at one.
- Questions about the user's current session ("what's in `df`?"): inspect, print, `View()` or plot in their own session (`list_sessions` shows the foreground one). Read-only there, or non-destructive commands like `print()` or `str()`.
- Other tools: `list_sessions` (ids, status, working dir), `get_session_history`, `get_plot`, `interrupt_session`. `run_positron_command` takes `command_id` and a positional `args` array; omit `args` when none. Useful ids: `workbench.action.language.runtime.getActiveSessions`, `.selectSession`, `.restartActiveSession`, `vscode.open` (absolute path; csv/parquet open in Data Explorer), `positronPackages.getAllPackages`. Look other ids up with `list_positron_commands`/`get_positron_command_guide`; unlisted ids may open a picker and block.
